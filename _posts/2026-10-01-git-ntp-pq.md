Tony Mattke wrote a series of [blog posts](https://routerjockey.com/git-for-network-engineers-part-1/) with detailed recommendations on how network engineers can leverage git.

In July 2026, a failure of the NTP service in Telstra caused a major outage. Telstra has published the [report](https://www.telstra.com.au/content/dam/tcom/dynamic-media-projects/luke-campbell/TAP-Findings-for-Telstra-Outage.pdf) describing this outage in detail.

A [report](https://nsarchive.gwu.edu/document/22835-document-01-defense-advanced-research-projects) describing the first decade of ARPANet history, published in April 1981.

[pqspy](https://addons.mozilla.org/en-US/firefox/addon/pqspy/) is a firefox add-on that allows to check whether the visited website is protected using Post Quantum cryptography.

[Svante Jurnell](https://www.linkedin.com/pulse/multi-dimensional-network-redundancy-why-its-crucial-harder-jurnell-mimff/) explains on linkedin the different types of redundancy that you need to consider when building a fully redundant network.

Every year, IETF participants publish Requests for Comments (RFC) on April 1st. The [RFC Editor](https://www.rfc-editor.org/) website now tags these RFCs with a special emoji, see e.g. [RFC3514](https://www.rfc-editor.org/info/rfc3514/).

A single football match retransmitted on a streaming platform has caused a [sevenfold increase of the traffic](https://www.linkedin.com/feed/?highlightedUpdateUrn=urn%3Ali%3Aactivity%3A7503793494210207744&highlightedUpdateType=COMMENTED_ON_UPDATE_MENTIONING_YOU&origin=INAPP&highlightedUpdateTrackingId=oHpUVMINSOma35FyffbGOw%3D%3D&showCommentBox=true) at the Piacenza Internet exchange in Italy.

The [NATJack attack](https://natjack.io) is a new type of attack against Network Address Translation.

A new look at TCP and DNS attacks. A recent [paper](https://arxiv.org/html/2609.09345v2) looks at what can happen when a malicious application running on a host can help to hijack TCP connections or DNS requests from this host. Interesting discussion on the behaviour of modern OSes.

[bgpmap.net](https://bgpmap.net/) is a new web site that allows to visualise BGP data from RIPE.

Stephen Weis announced that he broke the [896 bits RSA key challenge](https://saweis.net/posts/rsa-896.html) using 2048 GPUs for a period of about ten days. Breaking this key required about 30 years of GPU time.

In an [email posted on the NANOG mailing list](https://seclists.org/nanog/2010/Apr/193), Vint Cerf explains why he chose between 128 bits and 32 bits for the IPv4 addresses.


Peter Lowe has collected a lot of strange usages of the DNS in his [DNS Museum](https://dns.museum/). If you think that you know all usages of the DNS, check this virtual museum.
